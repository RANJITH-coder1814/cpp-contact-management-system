# cpp-contact-management-system
The Contact Management System is a console-based C++ application that allows users to store and manage contact details efficiently. Users can add, view, search, update, and delete contacts. The system uses file handling to permanently store contact data.

## 📌 Overview
The Contact Management System is a console-based C++ application that allows users to manage their contacts efficiently.

Users can:
- Add new contacts
- View all contacts
- Search contacts
- Update contact details
- Delete contacts

All contact data is stored using file handling.

---

## 🎯 Features
- Add Contact
- View All Contacts
- Search Contact by Name
- Update Contact
- Delete Contact
- Persistent storage using file handling

---

## 🛠 Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling (fstream)
